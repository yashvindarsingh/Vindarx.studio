## 🚀 Overview

**Vindar X Studio** is a high-performance, dark-themed digital agency web application. Built for modern businesses, it showcases custom web development, mobile apps, UI/UX design, and IT infrastructure services with fluid animations and responsive layouts.

### ✨ Key Features

- 🎨 **Dark High-Tech Design System:** Modern glassmorphic cards, glowing neon accents, and clean typography.
- 🎭 **Interactive GSAP Animations:** Smooth scroll triggers, staggered fade-ins, and interactive visual portals.
- 📱 **Fully Responsive Layout:** Optimized for screens ranging from 4K desktop displays down to mobile phones.
- ⚡ **Lightning Fast Performance:** Powered by Vite for instant component chunk loading and optimized asset delivery.
- 🌐 **Dynamic Status Detection:** Real-time online/offline network detection with custom error handling.
- 🛠️ **Full Section Suite:** Navbar, Hero, Stats, Services, Process, Work/Portfolio, Team, Approach, Contact, Custom 404, and Footer.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js (Hooks & Context API)
- **Routing:** React Router v6
- **Animations:** GSAP (GreenSock Animation Platform) + ScrollTrigger
- **Build Tool:** Vite
- **Styling:** Custom CSS3 (Flexbox & CSS Grid, Glassmorphism, CSS Variables)
- **Deployment:** Vercel / Netlify
